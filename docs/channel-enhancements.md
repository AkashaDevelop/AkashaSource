# 渠道模块功能增强文档

> ✨ 为 AKasha 渠道管理模块新增批量测试和右键菜单功能

## 📋 功能概览

本次更新为渠道管理模块添加了以下功能：

1. **批量测试连接弹窗** - 支持一键测试渠道的所有模型
2. **右键菜单** - 快捷访问常用渠道操作
3. **上游更新检测** - 自动检测和应用上游模型更新

## 🎯 新增功能详解

### 1. 批量测试连接弹窗

**功能描述**：
- 支持批量测试渠道配置的所有模型
- 实时显示每个模型的测试状态和响应时间
- 支持单独重新测试某个模型
- 端点类型选择（自动检测/OpenAI/Azure/Claude/Gemini）
- 测试模式开关
- 分页显示（每页30个模型）

**使用方法**：
1. 在渠道列表中，点击任意渠道行的"测试"图标
2. 在弹出的对话框中，选择端点类型（默认为自动检测）
3. 点击"测试全部 X 个模型"按钮开始批量测试
4. 查看每个模型的测试结果（成功/失败/响应时间）
5. 如需重新测试某个模型，点击该模型行的刷新按钮

**测试结果说明**：
- ✅ **成功**：显示绿色标记和响应时间（毫秒）
- ❌ **失败**：显示红色标记和错误信息
- ⏳ **测试中**：显示旋转的加载图标

### 2. 右键菜单

**功能描述**：
在渠道列表的任意行上点击右键，快速访问以下操作：

| 菜单项 | 功能说明 | 图标颜色 |
|--------|----------|----------|
| 测试连接 | 打开批量测试弹窗 | 蓝色 |
| 查询余额 | 查询渠道当前余额 | 绿色 |
| 获取模型 | 从上游拉取模型列表 | 紫色 |
| 上游更新 | 检测并应用上游模型变化 | 橙色 |
| 复制渠道 | 复制当前渠道配置 | 默认 |
| 删除 | 删除当前渠道 | 红色 |

**使用方法**：
1. 在渠道列表中，右键点击任意渠道行
2. 在弹出的菜单中选择需要执行的操作
3. 点击菜单项后自动执行相应功能

### 3. 上游更新检测

**功能描述**：
- 自动检测上游模型列表的变化
- 显示新增和移除的模型数量
- 一键应用更新到渠道配置

**使用流程**：
1. 右键点击渠道，选择"上游更新"
2. 系统自动检测上游模型变化
3. 如有更新，弹出确认对话框显示变化详情
4. 点击确认后自动应用更新并刷新渠道列表

## 🔧 技术实现

### 后端 API

#### 1. 批量测试模型
```
POST /api/channel/:id/test-batch
```

**请求体**：
```json
{
  "models": ["gpt-4", "gpt-3.5-turbo"],  // 可选，不传则测试所有模型
  "prompt": "你好"                        // 可选，测试问题
}
```

**响应**：
```json
{
  "code": 0,
  "data": {
    "results": [
      {
        "model": "gpt-4",
        "status": "成功",
        "response_time": 1250,
        "error": ""
      },
      {
        "model": "gpt-3.5-turbo",
        "status": "失败",
        "response_time": 0,
        "error": "API key invalid"
      }
    ],
    "total": 2,
    "success_count": 1,
    "failed_count": 1
  }
}
```

#### 2. 高级测试（支持端点类型）
```
POST /api/channel/:id/test-advanced
```

**请求体**：
```json
{
  "endpoint_type": "auto",  // auto | openai | azure | claude
  "test_mode": false
}
```

## 🚀 使用建议

1. **批量测试**：建议在添加新渠道或修改配置后，使用批量测试功能验证所有模型的可用性

2. **上游更新**：定期检查上游更新，确保渠道模型列表与上游保持同步

3. **右键菜单**：使用右键菜单可以快速访问常用操作，提高管理效率

4. **测试模式**：在生产环境中，建议关闭测试模式以避免产生额外费用

## 🐛 故障排查

### 问题1：批量测试全部失败

**可能原因**：
- 渠道 Key 无效
- Base URL 配置错误
- 上游服务不可用

**解决方法**：
1. 检查渠道配置中的 Key 和 Base URL
2. 单独测试每个模型定位问题
3. 查看错误信息获取详细原因

### 问题2：右键菜单不显示

**可能原因**：
- 浏览器阻止了右键菜单
- 表格行未正确绑定事件

**解决方法**：
1. 检查浏览器控制台是否有错误
2. 刷新页面重试
3. 使用表格中的按钮操作作为替代

### 问题3：上游更新检测失败

**可能原因**：
- 上游 API 不支持模型列表查询
- 网络连接问题

**解决方法**：
1. 确认渠道类型支持模型列表 API
2. 检查网络连接
3. 手动更新模型列表

## 📝 注意事项

1. **测试费用**：批量测试会向上游发送真实请求，可能产生费用
2. **并发限制**：批量测试采用并发方式，请注意上游 API 的速率限制
3. **权限要求**：所有功能均需要管理员权限
4. **浏览器兼容**：建议使用 Chrome/Edge/Firefox 等现代浏览器
